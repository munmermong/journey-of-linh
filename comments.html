Exploring the structure and design of my website

Structure • Design • Accessibility

01. Overall Website Structure

This personal portfolio presents my experiences, learning journey and future aspirations in computing. It contains four connected pages:

  • Home — An introduction to me and my journey.
  • My Past — Previous experiences and learning progress.
  • My Future — Goals, ambitions and future plans.
  • Comments — The website's structure and design decisions.

Visitors can move between pages using the navigation bar, footer links or the section timeline.

02. Internal Page Structure

All four pages follow a consistent layout, making the website easier to understand and navigate.

Element Purpose
Navigation bar Links to the four main pages.
Cover Introduces each page with a title and subtitle.
Main content Displays information in a two-column layout.
Journey timeline Links directly to sections within the current page.
Footer Provides additional navigation and design credits.

03. CSS Styles Used

CSS controls the website's layout, appearance and interactive effects. These are some of the main selectors used:

Selector Type Purpose
body Element Sets the general font, text colour and background.
.navbar Class Arranges and positions navigation links.
.cover Class Controls the page cover layout.
#cover-name ID Styles the main name heading on Home.
.content Class Creates the Home page's two-column layout.
.timeline-item Class Styles the links in the journey timeline.
:hover Pseudo-class Changes the appearance of links when hovered over.
@media Media query Adjusts the layout for smaller screens.

04. Graphic Design

The design uses warm, neutral colours to create a calm and personal atmosphere.

Colour Code Use
Cream #FAF6EA Main background
Beige #E8DCC5 Cover and footer
Brown #463D35 Main text
Terracotta #C58B70 Highlights and hover effects

Typography

  • Libre Baskerville: Main body text and headings.
  • Better Together: Decorative headings.
  • Simple Handmade: Selected subtitles.

Layout

  • Two-column content layout.
  • Consistent spacing and section numbering.
  • Sticky navigation and journey timeline.
  • Responsive layout for smaller screens.

05. Alternative Text and CSS Accessibility

The website uses HTML and CSS features to make its content easier to understand and navigate.

  • Alternative text: Images include descriptive alt attributes for screen readers and when images cannot load.
  • Semantic HTML: Elements such as nav, header, main, section and footer organise the content.
  • CSS disabled: Text and links remain available, but the visual layout, colours, fonts and timeline styling are no longer applied.
  • Responsive design: Media queries adjust the layout for smaller screens.
