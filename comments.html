A reflection on the design and development.

01. Overall Website Structure

My website is a personal portfolio that introduces me and shares my journey in computing. It is divided into four pages, each focusing on a different part of my story. The navigation bar allows visitors to move between pages, while the footer provides another way to access the main sections.

Page Purpose
Home Introduces me and gives an overview of my journey.
My Past Explores my earlier experiences and development in computing.
My Future Shares my ambitions, goals and possible career directions.
Comments Explains the website's structure, design and implementation.

02. Internal Page Structure

All four pages follow a consistent layout to make the website easier to navigate. The navigation bar appears at the top, followed by a page cover and the main content. The main area uses two columns: the wider column contains the page information, while the narrower column contains the journey timeline. The footer appears at the bottom of every page.

Element Purpose
Navigation Bar Provides links to the other pages.
Page Cover Displays the page title and a short introduction.
Main Content Contains the paragraphs, tables, lists and other information.
Journey Timeline Provides links to the main pages and highlights the current page.
Footer Contains additional navigation links and credits.

03. CSS Styles

CSS is used to control the appearance and layout of the website. I created reusable styles so that common elements, such as the navigation bar, page covers, timeline and footer, remain consistent across all pages.

CSS Selector Purpose
body Sets the main font, text colour and background colour.
.navbar Styles the navigation bar and its links.
.cover Controls the layout of the homepage cover.
#cover-name Styles the main name displayed on the homepage.
.content Controls the main content area.
.timeline-item Styles each link in the journey timeline.
:hover Changes the appearance of elements when the pointer moves over them.
@media Adjusts the layout for smaller screen sizes.

Examples of CSS Properties

  • display: grid; creates the two-column page layout.
  • position: sticky; keeps the journey timeline visible while scrolling.
  • border-radius gives selected elements rounded corners.
  • transition makes hover effects appear more smoothly.
  • max-width helps control the width of content.

04. Graphic Design

I chose a warm and neutral colour palette to create a calm, personal atmosphere. The colours are used consistently across the pages to help the website feel connected without making the content difficult to read.

Colour Palette

#FAF6EA — Main background
#E8DCC5 — Content boxes and highlights
#C58B70 — Accent colour and active links
#8F7965 — Secondary text
#463D35 — Main text

Typography

  • Libre Baskerville: Main body text and headings.
  • Better Together: Decorative headings.
  • Simple Handmade: Selected subtitles.

I used different font sizes and weights to establish a clear visual hierarchy. Larger headings help separate sections, while smaller text is used for descriptions and supporting information.

05. Accessibility and Other Considerations

I considered accessibility and usability while developing the website. Images include alternative text so that their content can be understood by visitors using screen readers. I also used semantic HTML elements to give the page a clearer structure.

  • Alternative text: Images include descriptive alt attributes.
  • Semantic HTML: Elements such as header, nav, main, section, aside and footer organise the content.
  • Responsive design: Media queries adjust the layout for smaller screens.
  • Readable content: Text is left-aligned with spacing between sections to make reading easier.
  • Navigation: Links are provided consistently across the website.

I also considered how the website would appear if CSS were disabled. The HTML structure still keeps the content in a logical order, allowing visitors to understand the information even without the visual styling.
